# Hangman Game

A simple word-guessing game built in **Python** as part of the **CodeAlpha Internship Program (Task 1)**.

The game randomly selects a word, and the player has to guess the word letter by letter within a limited number of attempts.

## How to Play

1. Run the Python script:

```bash
python Hangman.py
```

2. Guess one letter at a time.
3. You get 6 wrong attempts by default.
4. Guess all the letters correctly before the attempts run out to win.

## Features

* Random word selection
* Tracks wrong guesses and remaining attempts
* Shows already guessed letters
* Simple console interface

## Technologies Used

* Python 3
* `secrets` module

# 🎮 Hangman Game

A classic word-guessing console game built in **Python**, developed as part of the **CodeAlpha Internship Program (Task 1)**.

The game randomly selects a hidden word, and the player must guess it letter by letter before running out of attempts.

## 🚀 How to Play
1. Run the script:
```bash
   python Hangman.py
```
2. Guess one letter at a time.
3. You have a limited number of wrong attempts (default: 6).
4. Correctly guess all letters in the word before attempts run out to win!

## ✨ Features
- 🔀 Random word selection from a predefined word list
- 📊 Tracks wrong guesses and remaining attempts
- 📝 Displays already guessed letters
- 💻 Simple, clean, and interactive console interface

## 🛠️ Technologies Used
- Python 3
- `secrets` module (for secure random word selection)
